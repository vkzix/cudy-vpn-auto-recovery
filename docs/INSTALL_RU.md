# Установка Cudy VPN Auto Recovery

## Требования

- OpenWrt с BusyBox ash и procd.
- HomeProxy установлен и настроен.
- Mixed Proxy HomeProxy слушает `127.0.0.1:5330`.
- TUN-интерфейс называется `singtun0`.
- Установлены `curl` и `nftables`.

Проект разрабатывался на Cudy TR3000 v1 с OpenWrt 25.12.5. На других роутерах имена интерфейсов и портов могут отличаться.

## Установка

1. Скачайте репозиторий и распакуйте архив на роутере либо скопируйте папку проекта на устройство.
2. Перейдите в корневую папку проекта.
3. Запустите:

```sh
sh install.sh
```

Установщик проверит наличие HomeProxy, curl и nft, скопирует скрипты и зарегистрирует procd-службу `vpn-monitor`.

Если `/etc/vpn-auto-recovery.conf` уже существует, установщик не перезаписывает его.

## Настройка

Откройте:

```sh
vi /etc/vpn-auto-recovery.conf
```

Основные параметры:

| Параметр | Значение по умолчанию | Назначение |
|---|---:|---|
| `CHECK_INTERVAL` | 30 | Интервал проверки, секунд |
| `MAX_FAILS` | 5 | Ошибок подряд до восстановления |
| `COOLDOWN` | 900 | Защитная пауза, секунд |
| `TUN_INTERFACE` | singtun0 | Имя TUN-интерфейса |
| `PROXY_URL` | http://127.0.0.1:5330 | Mixed Proxy HomeProxy |
| `RECOVERY_ATTEMPTS` | 15 | Проверок после перезапуска |
| `RECOVERY_WAIT` | 4 | Пауза между проверками |
| `ENABLE_GAME_PORT_RULES` | 1 | Включить игровые правила |

Проверьте, что адрес Mixed Proxy и имя TUN-интерфейса совпадают с вашей конфигурацией HomeProxy.

## Проверка службы

```sh
/etc/init.d/vpn-monitor status
logread -e vpn-healthcheck -e vpn-recovery
```

Перезапуск:

```sh
/etc/init.d/vpn-monitor restart
```

## Удаление

```sh
sh uninstall.sh
```

Скрипт удаляет службу и установленные исполняемые файлы, удаляет собственную nftables-таблицу проекта, но сохраняет `/etc/vpn-auto-recovery.conf`.

## Важно

Скрипт восстановления перезапускает только HomeProxy. Он не выполняет `ifup wan`, не перезагружает firewall и не принуждает HomeProxy выбирать конкретную VPN-ноду.

Игровые правила касаются только пакетов с `ct status dnat`. Для входящих подключений также должны существовать соответствующие перенаправления портов в конфигурации firewall.
